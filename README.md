# Nexus — Estabilize o Sistema

**Nexus** é um jogo web de reflexo e precisão. O jogador controla um núcleo digital, coleta sinais de energia e precisa evitar interferências até alcançar a pontuação necessária para estabilizar o sistema.

## Objetivo do jogo

Alcançar **20 pontos** antes que a integridade do núcleo chegue a zero.

## Como jogar

- Pressione **INICIAR PARTIDA**.
- Use as teclas **← / →** ou **A / D** para mover o núcleo.
- Em dispositivos móveis, toque ou arraste o dedo na área do jogo.
- Colete os **sinais azuis** para ganhar **1 ponto**.
- Colete os **boosts dourados** para ganhar **3 pontos**.
- Evite as **interferências vermelhas**, que removem **1 ponto de integridade**.
- A dificuldade aumenta conforme a pontuação cresce.
- Pressione **P** para pausar ou continuar a partida.
- A partida termina em vitória ao atingir 20 pontos ou em derrota ao perder toda a integridade.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript puro (Vanilla JS)
- DOM, eventos, animação com `requestAnimationFrame` e Web Audio API

## Instalação / execução local

Não é necessário instalar dependências.

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador moderno.

Também é possível executar com uma extensão de servidor local, como Live Server, mas isso não é obrigatório.
